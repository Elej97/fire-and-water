# 🔥 Hand Gesture VFX Engine

A real-time cinematic visual effects engine built with JavaScript and MediaPipe Hands.

Control elemental powers like fire, ice, lightning, smoke, and energy particles using only your hand gestures through your webcam.

## ✨ Features

- 🔥 Fire particle effects
- ❄️ Ice energy effects
- ⚡ Lightning system with dynamic flashes
- 🌫️ Smoke orb & explosion effects
- ✋ Real-time hand tracking with MediaPipe
- 🎨 Cinematic dark-mode rendering
- 🖐️ Gesture detection:
  - Open hand
  - Pinch
  - Index finger pointing
- 💡 Dynamic lighting & glow effects
- 🎥 Webcam-based interaction

## 🎮 Controls

| Key | Mode |
|-----|------|
| `1` | Fire & Ice Mode |
| `2` | Lightning Mode |
| `3` | Red & Blue Energy Mode |

## 🛠️ Technologies Used

- JavaScript
- HTML5 Canvas
- MediaPipe Hands
- Camera Utils API

## 🚀 How to Run

1. Clone the repository:
```bash
git clone https://github.com/Elej97/fire-and-water.git
```

2. Open the project folder

3. Run with a local server (recommended)

Example using VS Code Live Server:
- Right click `index.html`
- Click `Open with Live Server`

## 📷 Requirements

- Webcam access
- Modern browser (Chrome recommended)
